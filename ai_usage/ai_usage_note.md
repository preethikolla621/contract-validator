## Known limitations I am aware of
- Duplicate order ids inside one batch are not flagged as `duplicate_key`; they are handled by the upsert and timestamp guard. Customers are flagged.
- The whole file is read into memory; only CSV and SQLite are supported.
- Timestamps are compared as ISO-8601 strings, which is correct only if all use the same UTC format.
